# 실시간 오프닝과 조용한 경기 음향

2026-10-17 요청 반영. 기존 아트와 실제 경기 장면을 카메라 구도·컷 편집으로 보여주는 오프닝입니다. 별도 렌더링 영화나 외부 영상 파일을 가져오지 않습니다.

## 참고 확인

- [넥슨 버블파이터 영상](https://www.youtube.com/watch?v=dBiWDSwu5ao): 시작의 얼굴/도구 클로즈업과 후반의 낮은 측면 액션을 브라우저에서 확인했습니다. 경기장 전경→준비→빠른 공 추적→타격 강조의 크기/속도 대비에 참고했습니다.
- [테니스의 왕자 스매시 히트 경기](https://www.youtube.com/watch?v=yevKYBlIUcg): 약1:00/2:00 선수 대사 클로즈업과1:20의 고정 경기 시점을 확인했습니다. 일반 랠리의 가독성을 유지하고 특별한 순간만 근접 컷으로 강조하는 데 참고했습니다.

영상·캐릭터·음악·대사는 복사하지 않았습니다. 현재 자체 스타일의 메시/포즈/셰이더를 사용하며 참고작과 동등한 인물 모델·수작업 애니메이션·조명 완성도를 확보했다는 의미는 아닙니다.

`Assets/Resources/FrontEnd/opening-edit.json`은 컷 시간/위치/주시점/FOV/롤을 정의합니다. 오프닝은 시작 시 자동 재생하고 Enter/Space/ESC/버튼으로 즉시 건너뜁니다. 타이틀의 “오프닝 다시 보기”로 반복할 수 있습니다. 움직임 줄이기는 이동·빠른 컷을 생략합니다. 일반 경기의 카메라는 바꾸지 않습니다.

`OpeningSequence`는 실제 경기장과 선수/공의 같은 메시·재질을 렌더합니다. 선수/공은 표시 전용 복제이고 실제 경기 렌더러는 저장된 값으로 복구합니다. 복제 모델의 collider는 비활성화합니다. 실제 공 상태/규칙/점수/게이지/stock/네트워크에는 쓰지 않고 global timeScale도 유지합니다. 서브/타격 효과음만 시퀀스의 편집 지점에서 재생합니다.

## 음향 규칙

| 상태 | BGM | 관중 |
| --- | --- | --- |
|오프닝·타이틀·선택|허용|경기 관중 루프 없음|
|서브 대기·폴트·렛·랠리|정지, 볼륨0|함성/환경음 정지|
|스킬 연출·일시정지|정지, 볼륨0|랠리 중 함성 없음|
|실제 득점 뒤 PointEnd|정지, 볼륨0|새 포인트당 함성1회|
|다음 서브|계속 정지|이전 함성·환경음 즉시 정지|
|경기 결과|결과 음악 허용|마지막 득점 반응 허용|

라켓·바운스·선수/심판 음성은 각각의 볼륨 설정을 유지합니다. 득점의 전자 멜로디 효과는 자동 재생하지 않습니다. 게스트도 보간된 포인트 합계를 기준으로 하며 입장/재접속 체크포인트에서 이전 함성을 반복하지 않습니다. 음소거는 사용자 BGM 슬라이더 값을 덮어쓰지 않아 메뉴에 돌아오면 원래 설정을 사용합니다. 기존 경기/듀스/긴장 곡의 A/B 버튼은 설정 화면에서만 청음합니다. 사람의 곡 선택은 아직 미정입니다.

함성은 원본 합성의 다중 비언어 발성과 박수 트랜지언트를 겹친 초안입니다. 기존 사용자 폴더의 cheer.wav는 덮어쓰지 않으므로 교체하려면 게임의 오디오 설정에 표시된 폴더에 새 파일을 복사하고 F5/다시 읽기를 누릅니다. 실제 관중 녹음 채택은 별도 청음 후 결정할 수 있습니다.

## 검증 방법

```sh
bash tools/unity.sh check
bash tools/unity.sh test-edit
bash tools/unity.sh test-front
bash tools/unity.sh build-mac
python3 tools/verify-polish.py --only intro --out .work/quality/cinematic
python3 tools/verify-polish.py --only audio --out .work/quality/cinematic
```

오프닝 검사는 자연 재생의 각 컷을 게임 카메라 PNG로 저장하고 자동 타이틀 전환·다시 보기·ESC 복귀·실제 공/점수/물리 tick/입력 차단을 검사합니다. 오디오 검사는 실제 adapter 입력과 AI로 랠리·득점·다음 서브를 진행하며 음악 볼륨0, 새 함성1회, 다음 서브에서 함성 정지를 측정합니다. 최종 결과는 [통합 검증 기록](polish-validation.md)에 추가합니다. 원시 영상/로그/WAV/빌드는 Git 밖에 둡니다.
