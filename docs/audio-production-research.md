# 음성·BGM 제작 및 청음 작업안

> 이 문서는 이전 설계/구현 기록입니다. 2026-10-16의 실제 선수 모델·15개 건축 테마·음원·외부 로더·설정은 [게임 완성도 개선](game-polish.md), 최신 증거는 [검증 결과](polish-validation.md)를 참고하세요.

조사 기준: 2026-10-15. 사용자가 먼저 듣고 선택할 수 있도록 음원 확보, 청음, Unity 연결 순서를 정리한 제작 계획입니다. 현재 게임의 음성·BGM은 미구현입니다. 시각 개선과 함께 진행하는 범위와 3인 분담은 [캐릭터와 게임 디자인 개선 계획](art-and-design-plan.md)을 참고하세요.

## 권장 순서

1. **작게 청음합니다.** BGM은 메뉴·기본 경기·결과의 3개 용도로 후보 A/B를 비교합니다. 스킬 고조는 짧은 효과음과 음악 음량 변화로 구성합니다. 음성 제작을 시작할 때는 한국·미국·모로코 캐릭터 3명으로 목소리 후보 A/B/C를 만들고, 각 후보가 같은 인사·스킬 대사를 읽게 합니다.
2. **승인한 방향만 확장합니다.** 캐릭터 15명의 준비/스킬/득점/패배 대사와 코트 테마를 만듭니다. 국가별 음악은 같은 경기 BPM/구조 위에 리듬·악기 색을 바꾸면 일관성이 좋습니다. 모든 국적을 한 악기나 억양으로 단순화하지 않습니다.
3. **게임 상황에서 다시 듣습니다.** 공 타격음과 심판 콜을 함께 틀고, 스킬 연출 중에는 BGM을 낮춰 목소리가 들리는지 확인합니다. 최종 결정은 개별 WAV 청음과 실제 랠리 청음 두 번으로 합니다.

## 작업 방법 비교

Voice Design은 설명에서 가상 음색을 만드는 기능입니다. [ElevenLabs 공식 Voice Design 문서](https://elevenlabs.io/docs/eleven-creative/voices/voice-design)를 기준으로 후보를 만들 수 있습니다. 무료 플랜은 상업 라이선스를 포함하지 않는다는 [공식 안내](https://help.elevenlabs.io/hc/en-us/articles/13313564601361-Can-I-publish-the-content-I-generate-on-the-platform)가 있으므로, 공개 게임과 포트폴리오 영상에 사용할 때는 선택한 플랜과 배포 범위를 함께 확인합니다.

[Eleven Music 공식 문서](https://elevenlabs.io/docs/eleven-creative/products/music)는 장면 설명을 통한 게임용 음악 시안을 안내합니다. [Suno의 최신 다운로드·약관 변경 안내](https://suno.com/blog/suno-updates-tos)와 [이용약관](https://suno.com/terms)은 무료/유료 및 다운로드 조건을 구분합니다. 서비스별로 결과의 이용 조건이 같다고 가정하지 않고, 채택한 음원마다 생성일·플랜·원본·권리 문서를 기록합니다. 현재 가격은 견적·선택 시점에 확인합니다.

## 장면별 BGM 구성

| 장면 | 음악 방향 | 전환 동작 |
| --- | --- | --- |
| 로고·타이틀 | 짧고 기억하기 쉬운 대표 선율 | 시작음 뒤 메뉴 음악으로 연결 |
| 메뉴·세계지도 | 밝은 전자음악·스포츠 팝·펑크 계열 | 선택 화면 사이에서 자연스럽게 지속 |
| 일반 경기 | 리듬이 분명하고 타격음을 가리지 않는 반복곡 | 득점·다음 서브마다 곡을 처음부터 틀지 않음 |
| 듀스·중요 포인트 | 기본 경기곡의 긴장 편곡 | 같은 박자에 맞춰 타악·베이스 층을 더하는 방식부터 검토 |
| 고유 스킬 | 짧은 상승·임팩트·복귀 효과 | 기존 1.2초 연출에 맞추고 경기 음악의 음량을 잠시 낮춤 |
| 승리·패배 | 대표 선율을 활용한 짧은 마무리 음악 | 경기곡을 페이드한 뒤 결과 음악 재생 |

첫 범위는 메뉴·경기·결과 음악 3종입니다. 긴장 편곡과 국가별 변주는 공통 선율과 반복 구조를 확정한 뒤 확장합니다. 악기별 분리 파일(stem)은 같은 박자·길이·시작점을 맞춰 준비해야 겹쳐 재생하기 쉽습니다.

## 먼저 만들 청음 패키지

| 묶음 | 수량과 길이 | 동일하게 비교할 것 |
| --- | --- | --- |
| 캐릭터 음색 파일럿 | 3명 × 후보 3 × 대사 2 = 18개, 각 1~4초 | 같은 대사, 같은 음량, 감정 과장 정도만 달리하기 |
| 심판 | 한국어/영어 후보 각 2명, 폴트·렛·아웃·듀스 샘플 | 명료도, 경기 중 묻히지 않는 발음 |
| BGM 파일럿 | 메뉴·경기 각 2개 20~30초, 결과 2개 5~8초 = 총 6개 | 가사 없음, 같은 용도끼리 같은 체감 음량으로 비교, 반복곡은 연결부 포함 |
| 스킬 효과 | 준비·임팩트·복귀 각 2안 = 6개 | 목소리 없이/목소리와 함께 두 번 듣기 |

청음 화면은 재생/정지, A/B 전환, 같은 음량 비교, 반복 재생, '채택/수정/보류'와 메모가 있으면 됩니다. 결과물은 브라우저에서 재생할 수 있는 WAV/OGG 파일 묶음과 로컬 청음 페이지로 전달할 수 있습니다. 원격 작업에서도 채팅에 음원을 첨부하거나 파일 링크로 직접 들을 수 있습니다. 청음 페이지와 실제 음원은 후속 제작 범위입니다. 기존 [청음 목록 CSV](audio-audition-plan.csv)는 브리프 목록이며 실제 음원 파일 목록은 아닙니다.

## 대사·음악 브리프 예시

한국 캐릭터 한서윤의 음색: '20대 후반 성인 여성, 차분하고 또렷한 중음, 집중할 때 짧고 단단해지는 호흡, 준비 대사는 자연스럽게, 스킬 대사는 힘 있게. 기존 배우/게임 인물의 목소리를 닮게 하지 않음.'

- 준비: '호흡 맞추고, 시작하자.'
- 스킬: '지금, 흐름을 바꾼다!'
- 득점: '좋아. 다음 공!'
- 실점: '한 포인트씩 다시.'

서울 코트 BGM 브리프: '가사 없는 현대 스포츠 전자음악. 경기의 박자를 해치지 않는 타악 리듬과 짧은 현악 질감, 새벽 강변의 여백. 30초 청음판과 반복 가능한 본편. 특정 게임/작곡가의 선율을 재현하지 않음.' 15개 코트의 mood 필드와 캐릭터 persona/costume은 작곡 브리프의 참고 자료이며 음악을 자동으로 확정하는 규칙은 아닙니다.

스킬 연출 1.2초는 0~0.35초 준비(짧은 상승음), 0.35~0.8초 임팩트(라켓/기하 리본), 0.8~1.2초 복귀(짧은 잔향)로 나눕니다. 음성 길이가 맞지 않으면 음성을 무리하게 빠르게 하기보다 대사를 줄입니다. 같은 캐릭터라도 매번 같은 외침만 반복되지 않게 2~3개 대사를 준비합니다.

## Unity에 연결할 때

`AudioMixer`를 Master → Music / Voice / SFX / Ambience로 나누고 각각 음량 조절을 제공합니다. 심판·캐릭터 음성 재생 시 Music을 잠시 낮추는 ducking과 준비/랠리/스킬/결과 상태별 snapshot을 구성합니다. 스냅샷은 여러 채널의 음량·효과 상태를 묶어 관리하는 설정입니다. [Unity Audio Mixer 공식 설명](https://docs.unity3d.com/6000.3/Documentation/Manual/AudioMixerSpecifics.html)

초기에는 Unity 기본 오디오 기능으로 구성합니다. 장면이 바뀌어도 하나의 재생 관리자가 유지되도록 하고, 메뉴와 경기 씬이 함께 로드될 때 음악이 두 번 재생되지 않게 합니다.

- 오디오는 점수나 물리를 결정하지 않습니다. 호스트가 확정한 판정 callId와 스킬 activationId를 받아 해당 소리를 한 번 재생합니다.
- 게스트는 같은 사건 ID를 수신했을 때 표시 시점에 맞춰 재생하고, 재접속한 과거 사건을 새 외침처럼 재생하지 않습니다. BGM은 각 PC에서 재생하며 오디오 샘플 자체를 WebSocket으로 중계하지 않습니다.
- 오프라인 일시정지와 온라인 로컬 메뉴의 음량 정책을 구분합니다. 온라인 메뉴나 개인 음량 설정은 상대의 경기와 음악을 바꾸지 않습니다.
- 빌드에 포함하는 긴 BGM은 Unity Import Settings의 Streaming을 후보로 사용하고, 짧은 음성·타격음은 지연이 적은 로드 방식을 선택합니다. 실제 PC 빌드에서 메모리와 반응을 측정합니다. [AudioClip 가져오기 설정](https://docs.unity3d.com/6000.3/Documentation/Manual/class-AudioClip.html)
- 원본 WAV와 배포용 압축본을 구분하고, 음량 설정·자막·음성 언어 선택을 별도 항목으로 둡니다.
- 최종 파일은 `characterId + cue + take + language`로 연결합니다. 예: `KOR_skill_02_ko.wav`. 국가 이름으로 음성이나 억양을 강제로 결정하지 않습니다.

음악 간 전환에는 두 재생 채널의 음량을 서서히 교차시키는 크로스페이드를 사용합니다. 반복 구간이나 박자에 맞춘 연결은 프레임 수 대신 오디오 시계에 예약하는 `AudioSource.PlayScheduled`를 검토합니다. 예약 재생을 사용해도 원본의 반복 구간이 잘못되어 있으면 틈이나 클릭음이 생길 수 있으므로 연결부 청음이 필요합니다. [Unity 예약 재생 API](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/AudioSource.PlayScheduled.html)

## 외부 CSV와 음원 교체 계획

현재 구현된 `characters.csv`, `gameplay.csv`, `effects.csv`와 별도로 오디오용 설정을 제안합니다. 아래 `audio.csv`와 외부 음원 로더는 새로 구현할 기능입니다. 경기 밸런스 파일과 오디오 파일을 하나의 호스트 설정으로 묶지 않습니다.

| 항목 | 제안하는 내용 | 변경 적용 |
| --- | --- | --- |
| 장면과 곡 연결 | `cue_id`, `scene`, 선택적 `court_id`, `track_id` | 장면에 맞는 곡을 선택 |
| 파일과 재생 값 | 파일 경로, 음량, 페이드 시간, 반복 구간, 필요한 곡의 BPM | 검증한 뒤 다음 전환에서 반영 |
| 사용자 취향 | 전체·BGM·효과음·음성·환경음 음량 | 해당 PC의 사용자 설정으로 저장 |
| 출처와 권리 | 제작자, 출처 URL, 라이선스, 생성일·플랜 또는 구매 자료 | 채택한 파일과 함께 기록 |

빌드에 포함된 AudioClip의 곡 선택·음량·페이드 값만 CSV로 바꾸는 방식과, 외부 WAV/OGG를 읽어 음원 자체까지 교체하는 방식은 구현 범위가 다릅니다. **새 파일의 빌드 없는 교체에는 비동기 외부 음원 로더가 필요**합니다. [Unity 오디오 파일 로드 API](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/Networking.UnityWebRequestMultimedia.GetAudioClip.html)를 활용하는 구성을 검토할 수 있습니다.

외부 로더는 파일을 미리 읽고 준비가 끝나면 전환합니다. 외부 파일에는 Unity Editor의 AudioClip Import Settings가 그대로 적용되지 않으므로 메모리·캐시·읽기 지연을 별도로 측정합니다. 잘못된 CSV, 누락 파일, 읽을 수 없는 음원이나 반복 구간 오류는 이전 정상 곡을 유지하고 이유를 표시합니다. 재읽기로 진행 중인 타격음이나 음악을 끊지 않게 합니다.

- 직접 제작하거나 의뢰할 때는 게임 배포·편집·포트폴리오 영상·원본 공개 범위를 정합니다.
- 공개 저장소에 포함할 후보로 CC0와 CC BY 음원을 검토할 수 있습니다. CC BY는 저작자·라이선스 링크·변경 사항 표시가 필요합니다. [CC0](https://creativecommons.org/publicdomain/zero/1.0/), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- 원본 공개가 허용되지 않는 에셋은 공개 저장소·공개 Git LFS에 올리지 않습니다. 필요한 경우 팀의 이용 조건에 맞는 비공개 보관과 공개 가능한 대체 리소스를 구성합니다.
- AI 생성곡도 생성 당시 이용 조건을 기록합니다. Suno는 무료 생성곡에 유료 구독 권한이 기본적으로 소급 적용되지 않는다고 안내합니다. 유료라는 이유만으로 원본 공개까지 허용된다고 가정하지 않습니다. [Suno 상업 이용 소급 안내](https://help.suno.com/en/articles/2425729)

## 오디오 작업 완료 기준

| 순서 | 전달할 결과 | 확인할 것 |
| --- | --- | --- |
| 1 후보 비교 | 메뉴·경기·결과의 A/B 6개와 출처·권리 기록 | 같은 용도끼리 체감 음량을 맞추고 채택/수정/보류 기록 |
| 2 본편 제작 | 채택한 반복곡·결과 음악과 필요 시 악기별 파일 | 반복곡을 10회 이어 듣고 틈·클릭음·반복 피로 확인 |
| 3 게임 연결 | 장면별 전환, 음량 설정, CSV와 선택한 파일 교체 방식 | 메뉴→경기→결과→재경기에서 중복 음악·갑작스러운 끊김 확인 |
| 4 통합 청음 | 타격·심판·스킬과 섞은 실제 경기 | 타격음과 콜이 묻히지 않는지, 일시정지·재접속·음량 저장 확인 |

현재 무음인 상태에서 효과음과 음성까지 함께 연결하려면 각 파일의 제작·선정도 작업에 포함합니다. BGM만 재생한 청음과 전체 소리를 섞은 청음을 구분합니다.

## 결정이 필요한 항목

실제 제작을 시작할 때 사용자가 결정할 것은 ① 녹음/음성합성 방식과 예산 ② 첫 지원 음성 언어 ③ 음색 A/B/C ④ BGM A/B ⑤ 과장된 외침의 정도입니다. 이 결정 전에는 유료 호출이나 음원 구매를 하지 않습니다. 청음 결과는 별도 manifest에 기록하고 승인된 파일만 게임 리소스로 연결합니다.
