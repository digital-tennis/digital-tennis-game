# 15명 선수의 이야기와 연출 정체성

모두 기존 이름·나이·성별·도시·문화적 배경을 유지한 가상의 성인 선수다. 아래 사건은 창작 서사이며 국적이나 혈통을 능력의 원인으로 설명하지 않는다. 한국·일본의 공동 워크숍 관계를 먼저 구체화하고 나머지 13명의 직업·생활과 코트 정체성으로 확장했다.

## 게임에서 읽기

시작 메뉴 → 1인 플레이/온라인/연습 → 선수 선택 → **선수 이야기**. 출발과 목표 / 약점·성장·관계 / 목소리와 연출의 세 탭을 읽고 **지도 보기**로 돌아간다. 이야기 안에서 방향키 또는 Enter/Space는 페이지 이동, Esc는 닫기다. 읽는 동안 선수 확정·서브는 실행되지 않는다. 상대 및 코트 선택에서도 현재 초점 선수의 프로필을 읽는다.

런타임 원본은 `Assets/Resources/Characters/roster.json`의 각 `narrative`이며 `CharacterProfile.narrative`로 로드한다. 프로필은 설명만 제공한다. 기존 스킬 수치, CSV, 물리, 네트워크 권위, 입력 어댑터는 서사로 변경하지 않는다.

목소리·대표 대사·소품·음악은 이 AC의 **서사 및 연출 디자인**이다. 여기의 새 대표 대사를 녹음·합성해 재생했다거나 소품 모델을 새로 구현했다는 뜻은 아니다. 기존 의상·스킬·코트에 의미를 연결했으며 음악 방향은 메뉴·소개·결과에만 해당한다. 경기/서브/랠리/스킬/일시정지 중 BGM은 계속 무음이다. 외부 사용자 음원 파일은 수정하지 않는다.

`python3 tools/verify-athlete-upgrade.py`는 별도 패키지 없이 실행한다. 런타임 카탈로그의 15명 기존 이름·성인 여부·모든 서사 항목을 검사하고, 각 선수의 한국어 문서가 해당 데이터와 일치하는지 대조한다. 관계 대상은 실제 다른 선수여야 하며 기술·코트 이름 연결과 소개용 음악 범위도 확인한다. 누락·이름 변경·미성년·잘못된 관계·끊어진 기술/코트 연결·복제 사건·오래된 문서를 주입하는 부정 테스트로 검증기가 실제 결함을 거부하는지도 확인한다. 이 명령은 서사 콘텐츠 검증만 수행하며 Unity UI 실행은 아래 명령으로 별도 확인한다.

EditMode 검증은 기존 15명 이름과 순서, 모든 서사 필드, 실제 선수 이름을 포함한 관계 대상, 중복되지 않는 사건·목소리, 기존 스킬·코트 연결 및 한국·일본 핵심 사건을 확인한다. PlayMode 검증은 실제 FrontEnd 씬에서 15명 × 3페이지를 열고 텍스트 잘림과 페이지 내용, 읽기 중 서브/선수 확정 차단, 닫은 뒤 선택 복귀를 확인한다. 이는 서사·프로필 검증이며 신규 모델·음성 재생·물리 Windows 테스트의 증거가 아니다.

이번 AC의 macOS Unity 6000.3.26f1 배치 실행에서 `bash tools/unity.sh test-edit` 159개와 `bash tools/unity.sh test-front` 6개가 통과했다. 후자는 15명 × 3페이지의 실제 UI 텍스트 높이도 검사한다. Null graphics 배치 테스트이므로 GPU 스크린샷이나 실제 음성 청음의 증거는 아니다. 결과 XML은 추적하지 않는 `.work/test-edit.xml`, `.work/test-front.xml`에 기록된다.
