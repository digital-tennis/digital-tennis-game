# 기존 경기 화면에 적용하는 코트 스킨

별도 웹 데모가 아니라 `FrontEnd`에서 시작하는 기존 Unity 경기 화면의 색상과 HUD 장식입니다. 새 경기 규칙이나 센서 프로토콜을 추가하지 않습니다.

## 사용 방법

1. Unity **6000.3.26f1**에서 프로젝트를 열고 `FrontEnd` 씬을 실행합니다.
2. 메인 메뉴 → 설정 → 키보드 조작 안내 옆 **코트 스킨 · 클럽**을 누르면 **기존**으로 전환됩니다. 다시 누르면 클럽으로 돌아옵니다.
3. 경기로 들어가 코트, 관중석, 전광판, 화면 점수판을 확인합니다. 선택은 해당 PC에 저장됩니다. 처음 실행할 때는 클럽이 기본입니다.

클럽은 세이지 계열의 하드 코트, 짙은 녹색 코트 주변, 차분한 관중석, 크림색 전광판 글자와 HUD 테두리를 사용합니다. 클레이는 흙색, 잔디는 잔디색을 유지하며 국가별 코트색·좌석색·장식색을 일부 섞습니다. 기존 스킨은 원래 색상 계산식과 전광판 글자색을 복원합니다.

국가별 건축물, 하늘, 조명, 선수, 공, 흰 경기선, 네트, 카메라 위치는 기존 구성을 사용합니다. 점수판 내용은 기존 실제 경기 상태에서 갱신됩니다. 스킨 선택은 온라인 상대에게 전송하지 않으며, 하드웨어 연결 없이 키보드로 확인할 수 있습니다.

## 적용 지점

- `CourtSkin.cs`: 로컬 선택 저장과 표면색. 배치 검증에서는 개인 설정을 읽거나 저장하지 않습니다.
- `NationalCourtView.cs`: 이미 생성한 코트·주변 머티리얼 인스턴스의 색상을 갱신합니다.
- `TennisStadium.cs`: 기존 좌석·국가별 장식·광장 렌더러와 전광판 글자색을 갱신합니다.
- `FrontEndView.cs`: 기존 HUD 패널과 설정 버튼을 구성합니다.

씬·머티리얼 에셋이나 GUID를 수정할 필요 없이 기존 컴포넌트에 적용됩니다. 스킨 전환은 코트 테마를 다시 선택하거나 경기 상태를 초기화하지 않습니다.

## 검증 상태와 남은 확인

2026-10-26 작업 PC에서 `bash tools/unity.sh check`를 실행했으나 Unity 6000.3.26f1이 설치되어 있지 않아 시작 전에 종료됐습니다. 따라서 **Unity 컴파일, 실제 화면, 빌드 검증은 아직 통과한 것으로 보고하지 않습니다.** README의 기존 경기 스크린샷은 새 스킨의 실행 증거가 아닙니다.

Unity가 있는 PC에서 다음을 확인한 뒤 PR을 검토 완료 상태로 전환합니다.

- `UNITY_EDITOR_PATH`를 설치된 Unity 실행 파일로 지정하고 `bash tools/unity.sh check` 실행.
- `FrontEnd`의 설정에서 클럽 → 기존 → 클럽 전환 후 경기 진입. 점수판, 입력 안내, 국가별 국기와 선수명이 가려지지 않는지 확인.
- 하드·클레이·잔디 코트에서 흰 선, 공, 선수의 시인성과 국가별 건축물 확인.
- 기존 스킨으로 돌아왔을 때 코트와 관중석, 전광판 글자색 복원 확인. 메뉴 복귀와 재실행 후 선택 유지 확인.
- 키보드 서브와 리턴으로 실제 점수·세트·게임 표시 확인. 온라인은 각 PC에서 서로 다른 스킨을 선택해도 같은 경기 상태를 표시하는지 확인.
- 실제 실행 화면을 캡처해 PR에 첨부. 그래픽 낮음·보통·높음과 움직임 줄이기 설정도 확인.

센서 동작 구분, 보드 펌웨어, BLE 연결 테스트는 이 시각 변경의 범위에 포함되지 않습니다.
